# 《重生之满级暴击》立项开发方案（LibGDX + Java 版本｜云麓盒子）

> 
> 游戏名称：重生之满级暴击
> 开发者：云麓盒子
> 引擎框架：LibGDX（Java）
> 定位：**全新独立原创2D肉鸽割草游戏**，脱离原有球球附属玩法，自有世界观、数值、美术、养成体系，支持 Windows / Android，单机 + 4人联机PVE + 无尽爬塔。
> Slogan：重生归零，暴击满级，每一次重来都是更强的自己

## 0 前置说明

LibGDX 基于 Java，跨平台，适合2D独立游戏；使用**全新空白工程从零开发，不移植、不复用任何其他游戏资源**。
核心品类框架：摇杆走位、自动锁敌攻击、打怪获取经验、升级三选一随机技能、波次刷怪+BOSSRush；**世界观、暴击核心机制、回溯印记、神装符文、天赋树全部原创**。

## 1 项目概述

### 1.1 目标平台

- PC：Windows
- 移动端：Android> 
> 可选扩展：HTML5（GWT，性能不推荐高怪量场景）、iOS（RoboVM，打包门槛高，本次不做优先目标）

### 1.2 核心差异化（和原版彻底切割）

1. 自研**满级暴击乘区系统**，伤害围绕暴击率、爆伤、暴击回溯、超额暴击阈值设计，主打爆发爽感；
2. **回溯印记重生机制**：每一局无论通关或失败都拿到永久属性，符合“重生”主题；
3. 养成体系：回溯印记、神装6件套、暴击符文、觉醒天赋树；
4. 技能池分为5大原创流派：暴击瞬杀流、极速连打流、虚空召唤流、壁垒生存流、重生回溯流；
5. 模式：主线裂隙闯关、4人联机组队、无尽暴击爬塔；
6. 美术：深空暗黑幻想风格，星空霓虹暴击特效，球形觉醒者主角，全部原创资源。

### 1.3 核心循环

进入对局 → 摇杆走位拉扯 → 自动武器锁敌打怪 → 获取经验升级 → 三选一技能构筑流派 → 精英/BOSS战、拾取暴击突破晶 → 结算拿到资源与回溯印记 → 局外养成变强 → 开启下一局挑战更高层数

## 2 技术方案：LibGDX Java 架构设计

### 2.1 依赖与库清单

- 核心：LibGDX 稳定版（1.12.1）
- 地图：Tiled（`.tmx` 地图，`TiledMap` 加载）
- UI：Scene2D + Skin（自研皮肤，不使用外部成套UI包）
- 序列化：Gson（JSON配置表、玩家存档）
- 联机：KryoNet（Java轻量网络库，主机权威模式，适合4人PVE）
- 对象池：LibGDX 内置 `Pool<T>`，用于子弹、怪物、召唤物、特效、经验球
- 输入：
  - PC：键盘WASD + 鼠标
  - Android：虚拟摇杆（Scene2D自定义TouchPad）
- 音频：LibGDX Audio，bgm、暴击音效、技能音效

> 
> 项目模块标准 LibGDX 结构：
> 
> 
> - `core`：主游戏逻辑（Java，所有业务写在这里）
> - `lwjgl3`：Windows桌面启动器
> - `android`：安卓启动器、权限配置、触屏适配

### 2.2 整体分层架构（core包内分包规划）

```
com.yunluhezi.maxcrit
├── asset        // 资源管理：AssetManager，图片、地图、音效、皮肤
├── config       // 配置数据模型：技能、怪物、装备、关卡、天赋（Gson读取json）
├── save         // 存档模块：玩家永久数据、回溯印记、装备、符文、天赋
├── battle       // 对局战斗核心（一局实例，局内临时数据）
│   ├── entity      // 实体：玩家、怪物、BOSS、召唤物、子弹、经验球
│   ├── wave        // 波次管理器，刷怪、时间难度膨胀、狂暴计时
│   ├── skill       // 技能系统、技能池、升级三选一逻辑
│   ├── damage      // 伤害计算器【自研暴击公式在这里】
│   └── pool        // 各类对象池
├── ui           // Scene2D UI：主菜单、背包、天赋、技能选择弹窗、结算面板、HUD
├── network      // KryoNet联机模块：主机/客户端消息、状态同步
├── screen       // GameScreen、MenuScreen、TalentScreen、BagScreen等屏幕
└── util         // 工具类：数学辅助、碰撞、随机权重、日志
```

### 2.3 核心数据设计

#### 2.3.1 暴击伤害计算公式（damage包）

```
最终伤害
= 基础攻击
* 流派倍率
* 神装套装系数
* 符文爆伤增幅
* 回溯印记永久加成
* 暴击判定系数
* 满级超额暴击系数（达到阈值才触发）
```

- 暴击判定：roll(0~100) < 当前暴击率 → 触发暴击
- 暴击回溯：暴击命中后，按比例回复血量/缩减主动技能CD
- 超额暴击：暴击率、爆伤叠满阈值，触发【满级暴击】，附带范围冲击波

#### 2.3.2 存档设计（Gson序列化JSON）

存档单独文件 `save/maxcrit_save.json`，不和任何其他游戏共用；
存档内容：回溯印记数量、已解锁神装、符文、天赋点、最高爬塔层数、历史最大暴击数值。

> 
> 存档校验：简单crc校验，防止手动篡改（单机原型够用）

### 2.4 联机方案（KryoNet，主机权威）

- 一局内**一名主机（Host）** 负责全部战斗计算：怪物AI、伤害、掉落、升级判定、BOSS技能；
- 客户端只负责：输入上报（摇杆方向）、表现同步（位置、血量、特效、UI）；
- 同步消息包：玩家输入包、实体状态包、升级选择包、掉落包、结算包；
- 限制：最多4人；原型阶段优先做局域网联机，后续可拓展公网（需要端口转发）。

### 2.5 性能关键点（LibGDX很容易踩坑）

1. 所有子弹、怪物、特效、经验球**强制使用 Pool<T> 对象池**，禁止频繁 `new`；
2. SpriteBatch 合批渲染，尽量减少batch.begin/end次数；
3. 屏幕外怪物休眠：暂停AI更新，只保留位置；进入屏幕再激活；
4. Tiled地图分层，静态图预渲染，动态实体单独渲染；
5. 移动端降帧策略：后台自动pause，降粒子数量上限；
6. 技能、怪物配置全部JSON驱动，不要硬编码数值。

## 3 系统详细设计

### 3.1 玩家实体（BattlePlayer）

- 圆形碰撞体；摇杆控制移动；
- 自动武器：自动扫描范围内敌人，按【距离优先+视野检测】锁定目标，自动发射；
- 局内属性：本局临时血量、移速、攻速、暴击率、爆伤、护盾、复活次数；
- 局外属性：开局读取存档的回溯印记、神装、符文、天赋，预计算基础面板带入对局。

### 3.2 波次系统 WaveManager

- 单关分阶段：小怪波 → 精英波 → BOSS波；
- 内置对局计时器：随时间增加怪物血量、移速、暴击抗性；超时进入狂暴难度；
- BOSS死亡固定产出【暴击突破晶】，用于本局主武器突破，改变攻击形态、解锁超额暴击。

### 3.3 技能升级系统（标志性肉鸽模块）

- 击杀怪物掉落经验球，磁铁类技能扩大拾取半径；
- 经验条满 → 暂停游戏，弹出Scene2D技能选择弹窗，**3选1**；
- 技能带权重配置，稀有技能抽取概率更低；技能可多次叠加升级，部分低级技能可进阶高级形态；
- 五大流派技能池全部原创，配置在 `config/skill.json`。

### 3.4 局外养成系统

1. **回溯印记**：通关/失败都产出，永久提升暴击率上限、爆伤；游戏名字核心机制；
2. **神装6部位**：武器、头冠、披风、护符、战靴、戒印；品质：凡品→精良→稀有→史诗→传世→神域→满级神话；2/4/6件激活套装效果；
3. **暴击符文**：镶嵌到装备，微调暴击率、爆伤、伤害穿透、对怪物增伤；
4. **觉醒天赋树**：瞬杀、永续、神佑三系，消耗天赋点解锁被动加成。

### 3.5 游戏模式

1. 裂隙闯关（主线）：线性关卡，解锁剧情场景（虚空初隙、星陨深渊、混沌边界、破晓终境）；
2. 神域组队：最多4人局域网联机，队友之间提供小幅暴击光环增益；
3. 无尽暴击爬塔：无上限层数，记录最高层数、历史单次最大暴击（核心排行榜数据，单机本地记录）。

## 4 美术与资源规范

- 分辨率基准：1280×720，适配安卓多分辨率（LibGDX Viewport + FitViewport）
- 风格：深空暗黑幻想、星空底色、金色暴击跳字、霓虹蓝紫流光特效
- 资源目录（`assets`）

```
assets
├── maps/      // Tiled tmx地图
├── textures/  // 角色、怪物、装备图标、特效图集（TexturePacker打包atlas）
├── ui/        // scene2d skin、面板
├── sound/     // 音效、BGM
└── config/    // json配置表：skill.json,monster.json,equip.json,talent.json
```

> 
> 图集必须用 TexturePacker 打包，减少drawcall。

## 7 风险点

1. KryoNet 在安卓网络不稳定：做超时重连、断线保存本局进度；
2. LibGDX 安卓内存溢出：资源及时unload、图集不要过大；
3. 数值爆炸：所有加成在配置表统一管理，乘区分开，预留调试开关；
4. 版权：所有美术、音效、文案原创，仅使用LibGDX、KryoNet、Gson开源库，遵循对应开源协议。
