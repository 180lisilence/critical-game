## 目录
- `p000_00.png` 形式命名，`p` 后三位是原图编号，后两位是该图内的块序号。
- `../sucai_parts_selected/`：过滤掉 <96px 噪点后的 756 个可用块。
- `组件清单.csv`：文件·来源图·分类·宽·高·尺寸档。
- `_sizes.csv`：含全部 842 块的可用标记。
- `_grid_big.png` / `_grid_mid.png` / `_grid_small.png`：按尺寸档的总览图。
- `_split_report.json`：每张原图拆出的块与包围盒坐标。

## 拆分方法
1. 四边带中值估计背景色；
2. 色距 + 亮度差生成前景 alpha；
3. 形态学开闭清理噪点；
4. 连通域提取，按面积过滤，逐块裁剪并压边 1px。

## 已知限制
- 连通域按"视觉连通"切分，文字、描边、装饰会被单独切成块，因此会产生一部分文字碎片和边框碎片；这些块保留在结果里，但不宜当作可交互组件。
- 块内保留原图深浅背景，不是透明底；需要透明底请指定具体文件名，单独处理。
- 同一张图内的块按左上到右下排序，文件名不含语义；语义命名需要人工过一遍。
- 块与块之间可能有 1–2px 重叠（裁切时留了 12px margin）。

## LibGDX 使用建议
- 先用 `sucai_parts_selected`，按尺寸档筛出自己要的部分；
- 图标类缩放到 128 或 256 后打进 TextureAtlas；
- 按钮、面板走 9-patch；
- 带文字的块只适合做静态背景或装饰，不要用于动态数值。
