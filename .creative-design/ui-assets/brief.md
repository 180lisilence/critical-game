# Brief｜《重生之满级暴击》UI 独立组件与图标

## 主题
把游戏 UI 拆成可直接接入 LibGDX 工程的独立组件与图标资产（不再从整图抠切）。

## 核心对象
2D 俯视肉鸽游戏《重生之满级暴击》的界面组件与功能图标。无实体商品。

## 视觉语言（统一）
- 2D 游戏 UI 素材，单件独立资产，主体居中占画面约 75%，四边留白 ≥8%。
- 背景：#0B0913 纯深紫黑，仅微弱径向暗光，无纹理噪点、无文字、无多余装饰。
- 材质：紫水晶 + 暗金描边，边缘锐利高光，少量紫色自发光。
- 用途：LibGDX 叠加到底板之上，需要边缘干净、单主体、可裁切。

## 清单（分 5 批）
1. 基础组件：主按钮、次按钮、关闭按钮、弹窗面板、物品卡片、血条、能量条、音量滑块
2. 货币与功能图标：星晶、金币、生命、护盾、暴击、宝箱、钥匙、设置
3. 系统图标：成就、排行榜、暂停、返回、音量、画质、存档、帮助
4. 状态 Buff 图标：无敌、狂暴、减速、中毒、回血、加速
5. 技能图标：6 个主动技能

## 画幅
- 图标 1:1 / 1024
- 按钮 3:1 / 1536×512
- 条形组件 4:1 / 1536×384
- 面板 1:1 / 1024
- 卡片 3:4 / 768×1024

## 禁止
文字、乱码、水印、二维码、多主体拼贴、渐变背景纹理、复杂场景。
