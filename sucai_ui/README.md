# sucai_ui｜独立 UI 组件与图标

## 目录
- `*.png`（36 张）：独立组件/图标，带深紫黑底，单主体居中，可直接作为 Sprite 或 Scene2D 控件底图。
- `alpha/*.png`（7 张）：按钮、面板、血条、能量条、滑块等框架类组件的透明底版。
- `alpha/_未采用/`：实验性抠图，边缘带渐变底色残留，未纳入使用。
- `UI素材清单.csv`：文件名 / 中文名 / 分组 / 尺寸 / 透明底对应关系。
- `_overview.png`：36 张总览。
- `_manifest.json`、`_sizes.json`：原始链接与尺寸记录。

## LibGDX 接入
1. 图标统一缩放到 128×128 或 256×256 后打进 TextureAtlas，减少 drawcall。
2. 按钮、面板按 9-patch 处理：在 `*.9.png` 中标记拉伸区，避免圆角变形。
3. 透明底框架类直接用作 `NinePatchDrawable` / `TextureRegionDrawable`，叠在底板之上。
4. 图标本身带深紫底，与 `#0B0913` 页面底色一致，视觉上无缝；如需完全透明，另行单独处理。
